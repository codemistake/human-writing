# Вебхуки

Вебхуки — способ получать уведомления о событиях в реальном времени: вместо опроса API наша система сама отправляет вам HTTP-запрос, когда что-то происходит. По сравнению с опросом это снижает и нагрузку, и задержку.

## Что такое вебхук

Вебхук — это HTTP-запрос, который наша система отправляет на указанный вами URL при наступлении события. Инициатор запроса — наша система, а не ваша.

## Настройка

1. Перейдите в раздел `/settings/webhooks` в личном кабинете.
2. Нажмите «Добавить вебхук» и укажите URL обработчика.
3. Выберите события, о которых хотите получать уведомления, например `payment.succeeded`.
4. Сохраните секретный ключ, который система сгенерирует по завершении настройки, — он показывается только один раз.

## Проверка подписи

Каждый запрос подписывается HMAC-SHA-256, подпись передаётся в заголовке `X-Signature`. Проверяйте подпись для каждого входящего запроса — это защита от подделки.

Чтобы проверить подпись, вычислите HMAC-SHA-256 от тела запроса с использованием секретного ключа и сравните результат со значением заголовка.

## Повторные попытки

Обработчик должен ответить кодом 2xx в течение 5 секунд. Если ответа нет или код отличается от 2xx, система повторит отправку — всего 3 попытки с возрастающим интервалом. Если все попытки неуспешны, событие помечается как недоставленное; отправить его повторно можно вручную из личного кабинета в течение 24 часов.

## Рекомендации

Обработчик должен быть идемпотентным: одно и то же событие может прийти больше одного раза. Отвечайте на запрос сразу, а обработку выполняйте асинхронно.
