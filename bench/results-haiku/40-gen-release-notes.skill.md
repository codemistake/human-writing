## 4.1

### Новое

**Параметр retry.** Добавлен параметр `retry` для количества повторов (по умолчанию 0).

**Разделение timeout.** Параметр `timeout` разделён на `connect_timeout` и `read_timeout` для более гибкой настройки. Старый параметр `timeout` работает, но помечен deprecated.

### Исправления

**Утечка соединений (#412).** Исправлена утечка соединений при исключении внутри контекстного менеджера.

**Кодировка заголовков (#398).** Исправлена неверная обработка заголовков с не-ASCII символами.

### Изменения требований

Минимальная версия Python поднята с 3.9 до 3.10.
