# Release notes v4.1

## Новое

**Параметр retry.** Добавлен параметр `retry` для количества автоматических повторов при ошибке. По умолчанию 0.

**Разделение timeout.** Параметр `timeout` разделён на `connect_timeout` и `read_timeout` для более гибкой настройки. Старый параметр `timeout` продолжает работать, но помечен как deprecated.

## Исправления

- Исправлена утечка соединений при исключении внутри контекстного менеджера (#412).
- Исправлена неверная кодировка заголовков с не-ASCII символами (#398).

## Изменения в совместимости

Минимальная версия Python повышена с 3.9 до 3.10.

## Миграция

Если вы используете параметр `timeout`, обновление совместимо, но рекомендуем перейти на `connect_timeout` и `read_timeout` явно для лучшей контроля над поведением.
