## Контекст

Наши сервисы общаются по REST. Это работало с тремя сервисами. Сейчас их двадцать, и REST показывает ограничения.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf — единственный источник истины.

REST остаётся для внешнего API и браузера. grpc-web добавляет сложность, которая на этом этапе не нужна.

## Последствия

Плюсы: строгие контракты, генерация клиентов, меньше оверхеда.

Минусы: команде нужно освоить новый инструментарий.

Это инвестиция, которая окупится.
