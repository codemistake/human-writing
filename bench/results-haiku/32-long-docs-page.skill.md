# Вебхуки

Вебхук — это HTTP-запрос, который система отправляет на указанный вами URL при наступлении события. Инициатором запроса является система, а не ваше приложение.

## Настройка

1. Перейдите в `/settings/webhooks` в личном кабинете.
2. Нажмите «Добавить вебхук» и укажите URL вашего обработчика.
3. Выберите события, о которых хотите получать уведомления, например `payment.succeeded`.
4. Сохраните. Система сгенерирует секретный ключ — сохраните его, так как он будет показан только один раз.

## Проверка подписи

Каждый запрос подписывается с использованием HMAC-SHA-256. Подпись передаётся в заголовке `X-Signature`. Проверяйте подпись для каждого входящего запроса.

Для проверки вычислите HMAC-SHA-256 от тела запроса с использованием секретного ключа и сравните результат со значением заголовка.

## Повторные попытки

Обработчик должен ответить кодом 2xx в течение 5 секунд. Если ответ не получен или код отличается от 2xx, система повторит отправку. Всего 3 попытки с возрастающим интервалом. Если все не удались, событие помечается как недоставленное и может быть отправлено вручную из личного кабинета в течение 24 часов.

## Рекомендации

Обработчик должен быть идемпотентным — одно и то же событие может быть доставлено несколько раз. Отвечайте на запрос немедленно, обработку выполняйте асинхронно.
