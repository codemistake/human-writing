# Вебхуки

## Что такое вебхук

Вебхук — это HTTP-запрос, который наша система отправляет на ваш URL при наступлении определённого события. Инициирует запрос наша система, не ваша.

## Настройка

Перейдите в `/settings/webhooks` в личном кабинете. Нажмите «Добавить вебхук» и укажите URL обработчика. Выберите события, которые хотите получать — например, `payment.succeeded`. Система сгенерирует секретный ключ; сохраните его, он будет показан только один раз.

## Проверка подписи

Каждый запрос подписан с помощью HMAC-SHA-256. Подпись передаётся в заголовке `X-Signature`. Проверяйте подпись для каждого входящего запроса:

1. Вычислите HMAC-SHA-256 от тела запроса, используя секретный ключ.
2. Сравните результат со значением заголовка `X-Signature`.

## Повторные попытки

Обработчик должен ответить с кодом 2xx в течение 5 секунд. Если ответ не получен или код ответа не 2xx, система повторит отправку 3 раза с возрастающим интервалом. Если все попытки не удались, событие помечается как недоставленное и может быть переотправлено вручную из личного кабинета в течение 24 часов.

## Рекомендации

Обработчик должен быть идемпотентным: одно и то же событие может быть доставлено больше одного раза. Отвечайте на запрос немедленно, обработку выполняйте асинхронно.
