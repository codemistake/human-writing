## Идемпотентность

Идемпотентность — это свойство операции, при котором её повторное выполнение даёт тот же результат, что и однократное.

Представьте: вы отправили запрос, но не получили ответ из-за сетевой ошибки. Повторить запрос? Но что, если первый уже выполнился? Идемпотентность решает эту проблему.

В HTTP метод PUT идемпотентен: сколько бы раз вы ни отправили один и тот же PUT, состояние ресурса останется одинаковым. POST — нет: каждый POST может создавать новую сущность.

Чтобы сделать POST безопасным для повторов, используют заголовок Idempotency-Key. Клиент генерирует уникальный ключ, сервер запоминает результат и при повторе с тем же ключом возвращает сохранённый ответ без повторного выполнения операции.

Идемпотентность позволяет безопасно повторять запросы, защищает от дублирования данных и делает систему надёжнее. Это необходимость для любого API, работающего в реальном мире.
