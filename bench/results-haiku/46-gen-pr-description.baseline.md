# Убран N+1 при загрузке заказов со связанным customer

## Что сделано

Оптимизирован эндпоинт списка заказов: теперь customer загружается за раз вместе с заказом, вместо отдельного запроса на каждый.

Использован SQLAlchemy `selectinload`.

## Результаты

На выборке из 1 200 заказов число запросов к БД упало с 1 201 до 3.

## Сопутствующие изменения

Добавлен индекс на `orders.customer_id` (миграция включена в PR).

## Тестирование

Добавлен интеграционный тест, который считает число запросов и падает при регрессии.

## Внимание

Миграция создаёт индекс без `CONCURRENTLY`. На боевой таблица `orders` большая — потребуется выполнить в окне обслуживания или использовать инструменты для анализа блокировок.
