## Убрана N+1 при загрузке заказов в списке

Связано: PERF-88

Используем `selectinload` при загрузке customer для каждого заказа. На выборке из 1 200 заказов число запросов упало с 1 201 до 3.

### Миграция

Добавлен индекс на `orders.customer_id`. Создаётся без `CONCURRENTLY`, поэтому на проде таблицу нужно блокировать. Решение: либо применить в окно обслуживания, либо переписать миграцию на конкурентное создание.

### Тесты

Добавлен тест, который считает число DB-запросов и падает при регрессии.
