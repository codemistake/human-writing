## Контекст

Наши сервисы общаются по REST. Сейчас их двадцать, и REST начинает показывать свои ограничения.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины.

REST остаётся для внешнего API и браузера. Grpc-web добавляет сложность, которая на текущем этапе не оправдана.

## Последствия

Мы получаем строгие контракты, генерацию клиентов и меньший оверхед. Команде придётся освоить новый инструментарий — это инвестиция, которая окупится.
