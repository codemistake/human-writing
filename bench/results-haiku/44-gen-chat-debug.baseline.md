Пода убивает по памяти. OOMKilled, exit code 137 — это классическая out-of-memory ситуация.

У тебя лимит 256Mi, но код пытается загрузить модель весом 1.2 GB. Легко переедет.

Два варианта:
1. Увеличить лимит в requests и limits до 2Gi как минимум (или больше, если модель займёт ещё место).
2. Если есть возможность — загружать модель лениво или использовать меньший формат модели.

Перезапусти с увеличенным лимитом и посмотри, будет ли стабильнее.
