Вот коротко: merge создаёт commit слияния и сохраняет историю целиком. Rebase переписывает историю, перенося твои коммиты поверх целевой ветки. После rebase нужен force push, что может напугать коллег на общей ветке.

Общее правило: merge — для общих веток, rebase — для локальных. Если есть вопросы — пишите.
