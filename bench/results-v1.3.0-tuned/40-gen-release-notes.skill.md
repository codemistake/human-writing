# Release notes 4.1

## Breaking

- Минимальная версия Python: 3.9 → 3.10.

## Новое

- Добавлен параметр `retry` — число повторов запроса, по умолчанию `0`.

## Изменения

- `timeout` разделён на `connect_timeout` и `read_timeout`. Старый `timeout` по-прежнему работает, но помечен deprecated.

## Исправления

- #412: утечка соединений при исключении внутри контекстного менеджера.
- #398: неверная кодировка заголовков с не-ASCII символами.
