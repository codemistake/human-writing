OOMKilled и exit code 137 — это убийство по памяти, а не баг в коде.

Лимит на под — 256Mi, а по логам видно, что перед обрывом он грузит веса модели размером 1.2 GB, это в разы больше лимита. 14 рестартов подряд как раз говорят, что упирается стабильно, а не разово.

Подними limits.memory (и requests, раз реально нужно больше 128Mi) с запасом выше 1.2 GB, чтобы веса помещались с учётом накладных расходов рантайма.
