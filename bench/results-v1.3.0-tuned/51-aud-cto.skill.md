p99 ответа API с вторника вырос с 380 мс до 4,2 с в часы пик.

Причина: пул соединений к PostgreSQL упирается в лимит 20, запросы ждут свободное соединение. Лимит выставили три года назад, с тех пор число подов выросло втрое.

Быстрое решение: поднять лимит до 60, один деплой. Правильное — вынести пул в PgBouncer, две недели работы.
