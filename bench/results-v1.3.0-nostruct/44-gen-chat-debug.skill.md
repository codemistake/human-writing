OOMKilled — под превышает лимит памяти в 256Mi, и его убивает (exit 137). Судя по логам, это происходит на загрузке весов модели: они сами по себе 1.2 GB, то есть почти в 5 раз больше лимита, и до конца загрузки процесс не доходит.

Restart Count 14 — значит с этим лимитом под падает по кругу с самого начала.

Нужно поднять memory limit (и request тоже) — навскидку хотя бы до 1.5–2Gi, чтобы весам хватило места плюс запас на рантайм.
