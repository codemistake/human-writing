Идемпотентность — свойство операции, при котором повторное выполнение даёт тот же результат, что и однократное.

Пример: клиент отправил запрос и не получил ответ из-за сетевой ошибки. Неизвестно, выполнился ли запрос на самом деле, а повторный вызов может задублировать операцию, если она не идемпотентна.

В HTTP метод PUT идемпотентен: сколько раз ни отправь один и тот же PUT, состояние ресурса не изменится. POST — нет: каждый POST может создать новую сущность.

Чтобы сделать POST безопасным для повторов, используют заголовок Idempotency-Key. Клиент генерирует уникальный ключ, сервер запоминает результат и при повторе с тем же ключом возвращает сохранённый ответ, а не выполняет операцию заново.

Идемпотентность позволяет безопасно повторять запросы, защищает от дублирования данных и делает систему надёжнее.
