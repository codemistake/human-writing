# Вебхуки

## Введение

Вебхуки — способ получать уведомления о событиях в реальном времени. По сравнению с опросом API они снижают нагрузку и задержку, поэтому это предпочтительный способ интеграции.

## Что такое вебхук

Вебхук — это HTTP-запрос, который наша система отправляет на указанный вами URL при наступлении определённого события. Инициатор запроса — наша система, а не ваша.

## Настройка

1. Перейдите в раздел `/settings/webhooks` в личном кабинете.
2. Нажмите «Добавить вебхук» и укажите URL вашего обработчика.
3. Выберите события, о которых хотите получать уведомления, например `payment.succeeded`.
4. Сохраните секретный ключ, который система сгенерирует после настройки — он показывается только один раз.

## Проверка подписи

Каждый запрос подписывается HMAC-SHA-256. Подпись передаётся в заголовке `X-Signature`. Проверяйте подпись у каждого входящего запроса — это защита от подделки.

Для проверки вычислите HMAC-SHA-256 от тела запроса с секретным ключом и сравните результат со значением заголовка.

## Повторные попытки

Обработчик должен ответить кодом 2xx в течение 5 секунд. Если ответа нет или код ответа отличается от 2xx, система повторяет отправку — всего 3 попытки с возрастающим интервалом. Если все попытки неуспешны, событие помечается как недоставленное; его можно отправить повторно вручную из личного кабинета в течение 24 часов.

## Рекомендации

Обработчик должен быть идемпотентным: одно и то же событие может быть доставлено больше одного раза. Отвечайте на запрос сразу, а саму обработку выполняйте асинхронно.

## Заключение

Вебхуки позволяют построить надёжную интеграцию в реальном времени.
