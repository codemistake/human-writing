Работа посвящена классификации обращений граждан. Традиционные методы решения этой задачи демонстрируют недостаточную эффективность. Предложена модель на основе архитектуры трансформер, обученная на корпусе из 1200 размеченных обращений. По результатам экспериментов значение F1 составило 0,87 против 0,79 у базовой модели.
