Идемпотентность — свойство операции, при котором её повторное выполнение даёт тот же результат, что и однократное.

Представьте: клиент отправил запрос, но не получил ответ из-за сетевой ошибки. Повторить запрос? А если первый всё-таки выполнился? Здесь и нужна идемпотентность.

В HTTP метод PUT идемпотентен: сколько раз ни отправь один и тот же PUT, состояние ресурса будет одинаковым. А вот POST — нет: каждый POST может создавать новую сущность.

Чтобы сделать POST безопасным для повторов, используют заголовок Idempotency-Key. Клиент генерирует уникальный ключ, сервер запоминает результат и при повторе с тем же ключом возвращает сохранённый ответ, а не выполняет операцию заново.

Идемпотентность позволяет безопасно повторять запросы и защищает от дублирования данных.
