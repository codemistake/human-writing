Это OOMKilled: exit code 137, лимит по памяти 256Mi. Последняя строка в логах перед обрывом — "Loading model weights (1.2 GB)", а сами веса уже больше лимита в 256Mi. Как только под вылезает за лимит, kernel его убивает.
