## Контекст

Наши сервисы общаются по REST. Это работало, пока сервисов было три. Сейчас их двадцать, и REST начинает показывать свои ограничения.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины.

REST остаётся для внешнего API и для браузера, потому что grpc-web добавляет сложность, которая на текущем этапе не оправдана.

## Последствия

С одной стороны, мы получаем строгие контракты, генерацию клиентов и меньший оверхед. С другой стороны, команде придётся освоить новый инструментарий. Это инвестиция, которая окупится.
