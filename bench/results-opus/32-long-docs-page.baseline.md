# Вебхуки

## Введение

Вебхуки — способ получать уведомления о событиях сразу, как они происходят. По сравнению с опросом API они снижают нагрузку и задержку, поэтому это предпочтительный способ интеграции.

## Что такое вебхук

Вебхук — HTTP-запрос, который наша система отправляет на указанный вами URL, когда происходит событие. Запрос инициирует наша сторона, а не ваша.

## Настройка

1. Перейдите в раздел /settings/webhooks в личном кабинете.
2. Нажмите «Добавить вебхук» и укажите URL вашего обработчика.
3. Выберите события, о которых хотите получать уведомления, например payment.succeeded.
4. Сохраните секретный ключ, который сгенерирует система. Он показывается только один раз.

## Проверка подписи

Каждый запрос подписывается по HMAC с алгоритмом SHA-256, подпись передаётся в заголовке X-Signature.

Проверяйте подпись у каждого входящего запроса — без этого запрос можно подделать. Для проверки вычислите HMAC-SHA-256 от тела запроса с вашим секретным ключом и сравните результат со значением заголовка.

## Повторные попытки

Обработчик должен ответить кодом 2xx в течение 5 секунд. Если ответа нет или код отличается от 2xx, система отправит запрос повторно — всего 3 попытки с возрастающим интервалом.

Если все попытки неуспешны, событие помечается как недоставленное. Отправить его повторно вручную можно из личного кабинета в течение 24 часов.

## Рекомендации

Сделайте обработчик идемпотентным: одно и то же событие может прийти больше одного раза.

Отвечайте на запрос сразу, а обработку выполняйте асинхронно — иначе легко упереться в лимит 5 секунд.
