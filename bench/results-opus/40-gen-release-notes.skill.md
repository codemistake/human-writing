# 4.1

## Требует внимания

- Минимальная версия Python поднята с 3.9 до 3.10.
- Параметр `timeout` разделён на `connect_timeout` и `read_timeout`. Старый `timeout` продолжает работать, но помечен deprecated.

## Новое

- Параметр `retry`: число повторов, по умолчанию `0`.

## Исправления

- #412: утечка соединений при исключении внутри контекстного менеджера.
- #398: неверная кодировка заголовков с не-ASCII символами.
