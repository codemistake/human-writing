## Контекст

Сервисы общаются по REST. Это работало, пока сервисов было три. Сейчас их двадцать, и ограничения REST стали заметны.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины о контрактах.

REST остаётся для внешнего API и для браузера: grpc-web добавляет сложность, которая на текущем этапе не оправдана.

## Последствия

Получаем строгие контракты, генерацию клиентов и меньший оверхед. Взамен команде придётся освоить новый инструментарий.
