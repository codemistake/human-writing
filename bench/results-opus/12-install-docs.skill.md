## Установка

Для работы нужен Docker.

1. Скопируйте `.env.example` в `.env` и заполните переменную `DATABASE_URL`.
2. Запустите сервисы:

   ```
   docker compose up -d
   ```

После запуска приложение будет доступно на `localhost`, порт 8080. Первый запуск может занять несколько минут: загружаются образы.

Установка завершена.
