# 4.1

## Ломающие изменения

- Минимальная версия Python поднята с 3.9 до 3.10.

## Новое

- Параметр `retry` — число повторов запроса. По умолчанию 0, то есть без явной настройки поведение не меняется.
- `timeout` разделён на `connect_timeout` и `read_timeout`. Старый `timeout` продолжает работать, но помечен deprecated.

## Исправления

- #412: утечка соединений, если внутри контекстного менеджера возникало исключение.
- #398: неверная кодировка заголовков с не-ASCII символами.
