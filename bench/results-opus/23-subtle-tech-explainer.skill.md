Идемпотентность — это свойство операции, при котором её повторное выполнение даёт тот же результат, что и однократное.

Она нужна, когда клиент отправил запрос и не получил ответ из-за сетевой ошибки: неизвестно, выполнился первый запрос или нет, а повторить его надо безопасно.

В HTTP метод PUT идемпотентен: сколько бы раз вы ни отправили один и тот же PUT, состояние ресурса будет одинаковым. POST — нет, каждый POST может создавать новую сущность.

Чтобы сделать POST безопасным для повторов, используют заголовок Idempotency-Key. Клиент генерирует уникальный ключ, сервер запоминает результат и при повторе с тем же ключом возвращает сохранённый ответ, а не выполняет операцию заново. Так повтор не создаёт дубликат данных.
