# Идемпотентность

Операция идемпотентна, если её повторное выполнение даёт тот же результат, что и однократное.

Это нужно, когда клиент отправил запрос и не получил ответ из-за сетевой ошибки. Он не знает, выполнился запрос или нет. Повторять его безопасно только тогда, когда операция идемпотентна: иначе повтор сделает работу второй раз.

В HTTP метод PUT идемпотентен: сколько одинаковых PUT ни отправь, состояние ресурса будет одним и тем же. POST — нет: каждый POST может создать новую сущность.

Чтобы повторы POST были безопасны, используют заголовок Idempotency-Key. Клиент генерирует уникальный ключ, сервер запоминает результат и при повторе с тем же ключом возвращает сохранённый ответ, а не выполняет операцию заново.

Итог: идемпотентность позволяет безопасно повторять запросы и не получать дубли данных.
