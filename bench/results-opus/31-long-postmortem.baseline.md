# Постмортем: недоступность публичного API 3 сентября

## Краткое описание

3 сентября с 11:47 до 13:20 публичный API был полностью недоступен всем клиентам — 93 минуты. Причина: истёк TLS-сертификат на ingress-контроллере, а cert-manager не перевыпустил его из-за собственного сбоя.

## Хронология

**11:47** — Prometheus зафиксировал рост ошибок TLS handshake до 100%. Алерт не ушёл: правила алертинга на эту метрику не было.

**11:52** — в поддержку начали поступать обращения клиентов.

**12:05** — сотрудник поддержки вручную поднял дежурного инженера через PagerDuty.

**12:10** — дежурный начал диагностику.

**12:35** — выяснили, что сертификат истёк в 11:47.

**12:40** — попытка перевыпустить сертификат вручную через cert-manager не удалась: под cert-manager был в CrashLoopBackOff с 28 августа.

**12:55** — cert-manager перезапущен с исправленной конфигурацией.

**13:12** — сертификат перевыпущен через Let's Encrypt.

**13:20** — API полностью восстановлен.

## Причины

Непосредственная: истёк TLS-сертификат. Он выпускается автоматически на 90 дней и должен перевыпускаться за 30 дней до истечения.

Корневая: cert-manager перезапускался в цикле с 28 августа — при плановом апгрейде кластера некорректно обновились CRD. Автоматический перевыпуск не работал 7 дней.

Способствующий фактор: не было алертов ни на срок истечения сертификата, ни на состояние подов cert-manager.

## Влияние

93 минуты API был недоступен для 100% клиентов. По предварительной оценке это затронуло около 12% дневного объёма запросов. Мобильные приложения, работающие через этот API, показывали ошибку соединения.

## Что сработало хорошо

Сотрудник поддержки сам эскалировал проблему дежурному инженеру, не дожидаясь алерта, — это сократило время реакции.

## Что нужно улучшить

1. Добавить алерт в Prometheus на истечение сертификата менее чем через 14 дней.
2. Добавить алерт на поды в состоянии CrashLoopBackOff в namespace cert-manager.
3. Включить проверку состояния cert-manager в чеклист планового апгрейда кластера.
4. Провести аудит всех автоматических процессов, поломка которых не вызывает алертов.
