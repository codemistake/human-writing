# Код-ревью

У нас две основные ветки: main и develop. В main код попадает только через develop, после тестирования.

Каждому pull request нужно два одобрения, минимум одно — от владельца кода из CODEOWNERS.

Сливаем через squash, чтобы история оставалась читаемой.

Если что-то непонятно — спрашивайте. Лучше спросить, чем сломать.
