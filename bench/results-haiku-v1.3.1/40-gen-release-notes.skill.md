# Версия 4.1

## Новое

- Параметр `retry`: число повторов при ошибке соединения (по умолчанию 0).
- Параметр `timeout` разделён на `connect_timeout` и `read_timeout`. Старый параметр `timeout` по-прежнему работает, но помечен deprecated.

## Минимальная версия

Поддержка Python 3.9 прекращена. Минимальная версия — Python 3.10.

## Исправления

- #412: утечка соединений при исключении внутри контекстного менеджера.
- #398: неверная кодировка заголовков с не-ASCII символами.
