## Контекст

Наши сервисы общаются по REST. Это работало, пока сервисов было три. Сейчас их двадцать, и REST начинает показывать свои ограничения.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины для контрактов.

REST остаётся для внешнего API и браузера, потому что grpc-web добавляет ненужную сложность на этом этапе.

## Последствия

Получаем: строгие контракты, генерацию клиентов и меньший оверхед.

Требуется: освоить новый инструментарий. Это инвестиция, которая окупится.
