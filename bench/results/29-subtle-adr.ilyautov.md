## Контекст

Наши сервисы общаются по REST. Работало, пока сервисов было три. Сейчас их двадцать, и REST начинает трещать по швам.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины по контрактам.

REST остаётся для внешнего API и для браузера: grpc-web добавляет сложность, которая сейчас не оправдана.

## Последствия

Плюсы: строгие контракты, генерация клиентов, меньший оверхед. Минус: команде придётся освоить новый инструментарий. Мы считаем, что это того стоит.
