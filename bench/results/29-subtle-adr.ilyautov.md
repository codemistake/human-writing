## Контекст

Наши сервисы общаются по REST. Пока сервисов было три, это работало. Сейчас их двадцать, и ограничения REST стали заметны.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины для контрактов между сервисами.

REST остаётся для внешнего API и для браузера: grpc-web добавляет сложность, которая на текущем этапе не оправдана.

## Последствия

Плюсы: строгие контракты, генерация клиентов, меньший оверхед. Минус: команде придётся освоить новый инструментарий. Это оправданная инвестиция.
