Идемпотентность - свойство операции, при котором повторное выполнение даёт тот же результат, что и однократное.

Типичный случай: клиент отправил запрос и не получил ответ из-за сетевой ошибки. Повторять запрос рискованно - вдруг первый всё-таки выполнился. Для этого и нужна идемпотентность.

В HTTP метод PUT идемпотентен: сколько раз ни отправь один и тот же PUT, состояние ресурса будет одинаковым. POST - нет: каждый POST может создать новую сущность.

Чтобы обезопасить POST от повторов, используют заголовок Idempotency-Key. Клиент генерирует уникальный ключ, сервер запоминает результат и при повторе с тем же ключом отдаёт сохранённый ответ, а не выполняет операцию заново.

Идемпотентность защищает от дублирования данных и делает систему надёжнее - для API, работающего в реальном мире, это необходимость, а не факультативная практика.
