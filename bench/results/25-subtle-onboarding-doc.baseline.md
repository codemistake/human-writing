У нас две основные ветки: main и develop. В main попадает только код, прошедший через develop и протестированный.

Каждый pull request должен получить два одобрения, хотя бы одно — от владельца кода из CODEOWNERS.

При слиянии используем squash, чтобы история оставалась чистой.

Если что-то непонятно — спрашивайте. Лучше спросить, чем сломать.
