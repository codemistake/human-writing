Это OOMKilled: exit code 137, лимит по памяти 256Mi. В логах видно, что перед обрывом под грузит веса модели весом 1.2 GB — это уже больше лимита, поэтому его убивает ядро, как только он начинает разворачивать веса в память.

Подними limits.memory заметно выше 1.2 GB, с запасом на рантайм, а не впритык, и requests подтяни следом, иначе слот на ноде не совпадёт с реальным потреблением.
