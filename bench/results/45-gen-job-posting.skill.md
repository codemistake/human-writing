# Backend-разработчик (Go)

Платёжный сервис, команда из четырёх человек, один из них тимлид.

## Стек

Go, PostgreSQL, Kubernetes, gRPC.

## Требования

- опыт с Go от 3 лет
- опыт с PostgreSQL в проде
- понимание Kubernetes на уровне пользователя

Плюсом будет опыт с платёжными системами.

## Задачи

Развитие сервиса проведения платежей, участие в дежурствах — раз в месяц, оплачивается.

## Условия

Удалённо из любой страны или офис в Москве. Вилка 250–350 тысяч рублей на руки. Оформление по ТК или по контракту.

## Процесс отбора

Звонок с тимлидом (30 минут) → техническое интервью (1,5 часа) → разговор с руководителем.
