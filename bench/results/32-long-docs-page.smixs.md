# Вебхуки

## Введение

Вебхуки - способ получать уведомления о событиях в реальном времени, без опроса API. Меньше нагрузка, меньше задержка.

## Что такое вебхук

Вебхук - это HTTP-запрос, который наша система отправляет на указанный вами URL при наступлении события. Инициатор запроса - наша система, не ваша.

## Настройка

1. Перейдите в раздел /settings/webhooks в личном кабинете.
2. Нажмите «Добавить вебхук» и укажите URL обработчика.
3. Выберите события, о которых хотите получать уведомления, например payment.succeeded.
4. Сохраните секретный ключ, который система покажет после настройки - второй раз он не появится.

## Проверка подписи

Каждый запрос подписан HMAC-SHA-256, подпись передаётся в заголовке X-Signature. Проверяйте подпись для каждого входящего запроса - это защита от подделки.

Для проверки посчитайте HMAC-SHA-256 от тела запроса с вашим секретным ключом и сравните результат со значением заголовка.

## Повторные попытки

Обработчик должен ответить кодом 2xx в течение 5 секунд. Если ответа нет или код не 2xx, система повторит отправку - всего 3 попытки с возрастающим интервалом. Если все три не сработали, событие помечается недоставленным, и его можно отправить повторно вручную из личного кабинета в течение 24 часов.

## Рекомендации

Обработчик должен быть идемпотентным, потому что одно и то же событие может прийти больше одного раза. Отвечайте на запрос сразу, а саму обработку выносите в асинхронную задачу.

## Заключение

Вебхуки дают надёжную интеграцию в реальном времени. Вопросы - в поддержку.
