# Вебхуки

## Введение

Вебхуки - предпочтительный способ интеграции по сравнению с опросом API: меньше нагрузки и задержки.

## Что такое вебхук

Вебхук - это HTTP-запрос, который наша система отправляет на указанный вами URL при наступлении события. Инициатор запроса - наша система, а не ваша.

## Настройка

1. Перейдите в раздел /settings/webhooks в личном кабинете.
2. Нажмите «Добавить вебхук» и укажите URL вашего обработчика.
3. Выберите события, о которых хотите получать уведомления, например payment.succeeded.
4. Сохраните секретный ключ - система покажет его только один раз.

## Проверка подписи

Каждый запрос подписывается HMAC с SHA-256, подпись передаётся в заголовке X-Signature. Проверяйте подпись у каждого входящего запроса, чтобы защититься от подделки.

Для проверки вычислите HMAC-SHA-256 от тела запроса с использованием секретного ключа и сравните результат со значением заголовка.

## Повторные попытки

Обработчик должен ответить кодом 2xx в течение 5 секунд. Если ответа нет или код не 2xx, система повторит отправку: всего 3 попытки с возрастающим интервалом. После неудачных попыток событие помечается как недоставленное, его можно отправить повторно вручную из личного кабинета в течение 24 часов.

## Рекомендации

Обработчик должен быть идемпотентным: одно и то же событие может прийти больше одного раза. Отвечайте на запрос сразу, а обработку выполняйте асинхронно.

## Заключение

Вебхуки позволяют построить надёжную интеграцию в реальном времени.
