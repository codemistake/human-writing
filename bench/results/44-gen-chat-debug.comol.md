OOMKilled: под убивают за превышение memory limit (256Mi), exit code 137 это подтверждает, а 14 рестартов значит, что падает стабильно, не разово.

По логам видно последнее перед обрывом: "Loading model weights (1.2 GB)" — модель весит 1.2 ГБ, а лимит 256Mi, она физически не влезает и крашится ещё на загрузке весов.

Подними memory limit с запасом под размер модели плюс сам рантайм, и requests подтяни ближе к limit, чтобы шедулер не сажал под на ноду, где памяти реально не хватит.
