## Контекст

Сервисы общаются по REST. Это работало, пока сервисов было три. Сейчас их двадцать, и REST начинает мешать.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины по контрактам между сервисами.

REST остаётся для внешнего API и браузера: grpc-web добавляет сложность, которая сейчас не оправдана.

## Последствия

Плюсы: строгие контракты, генерация клиентов, меньший оверхед. Минус: команде нужно освоить новый инструментарий.
