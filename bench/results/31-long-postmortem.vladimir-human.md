# Постмортем: недоступность публичного API 3 сентября

## Краткое описание

3 сентября с 11:47 до 13:20 публичный API был полностью недоступен для всех клиентов — 93 минуты. Причина: истёк TLS-сертификат на ingress-контроллере, а cert-manager не смог перевыпустить его вовремя из-за собственного сбоя.

## Хронология

11:47 — Prometheus зафиксировал рост ошибок TLS handshake до 100%. Алерт не сработал: правила для этой метрики не было.

11:52 — в поддержку начали поступать обращения клиентов.

12:05 — сотрудник поддержки вручную вызвал дежурного инженера через PagerDuty.

12:10 — дежурный начал диагностику.

12:35 — выяснилось, что сертификат истёк в 11:47.

12:40 — попытка вручную перевыпустить сертификат через cert-manager не удалась: под cert-manager находился в CrashLoopBackOff с 28 августа.

12:55 — cert-manager перезапущен с исправленной конфигурацией.

13:12 — сертификат перевыпущен через Let's Encrypt.

13:20 — API полностью восстановлен.

## Причины

Непосредственная причина — истечение сертификата. Он выпускается автоматически на 90 дней и должен перевыпускаться за 30 дней до истечения.

Корневая причина — cert-manager с 28 августа перезапускался в цикле из-за некорректного обновления CRD при плановом апгрейде кластера. Из-за этого автоматический перевыпуск не работал 7 дней.

Способствующий фактор — не было алерта ни на срок истечения сертификата, ни на состояние подов cert-manager.

## Влияние

93 минуты публичный API был недоступен для всех клиентов. Это затронуло около 12% дневного объёма запросов. Мобильные приложения показывали ошибку соединения.

## Что сработало хорошо

Сотрудник поддержки сам эскалировал проблему дежурному инженеру, не дожидаясь автоматики, — это сократило время реакции.

## Что нужно улучшить

1. Добавить в Prometheus алерт на истечение сертификата менее чем через 14 дней.
2. Добавить алерт на поды cert-manager в состоянии CrashLoopBackOff.
3. Включить проверку состояния cert-manager в чеклист планового апгрейда кластера.
4. Провести аудит автоматических процессов, у которых нет алертов на отказ.
