Идемпотентность — свойство операции, при котором повторное выполнение даёт тот же результат, что и однократное.

Типичный случай: клиент отправил запрос и не получил ответ из-за сетевой ошибки. Непонятно, стоит ли повторять запрос — сервер мог уже выполнить первый.

В HTTP метод PUT идемпотентен: сколько раз ни отправь один и тот же PUT, состояние ресурса будет одинаковым. POST — нет: каждый POST может создать новую сущность.

Чтобы сделать POST безопасным для повторов, используют заголовок Idempotency-Key. Клиент генерирует уникальный ключ, сервер запоминает результат и при повторе с тем же ключом возвращает сохранённый ответ, а не выполняет операцию заново.

Идемпотентность позволяет безопасно повторять запросы и защищает от дублирования данных.
