# 4.1

## Breaking changes

- Минимальная версия Python поднята с 3.9 до 3.10.

## Deprecations

- Параметр `timeout` разделён на `connect_timeout` и `read_timeout`. Старый `timeout` продолжает работать, но помечен deprecated — переходите на новые параметры.

## New features

- Добавлен параметр `retry` — число повторов запроса, по умолчанию 0.

## Bug fixes

- #412: исправлена утечка соединений при исключении внутри контекстного менеджера.
- #398: исправлена неверная кодировка заголовков с не-ASCII символами.
