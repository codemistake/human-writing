Идемпотентность — свойство операции, при котором повторное выполнение даёт тот же результат, что и однократное.

Пример: клиент отправил запрос и не получил ответ из-за сетевой ошибки. Повторить запрос? Не факт, что первый не выполнился, — тут и нужна идемпотентность.

PUT в HTTP идемпотентен: сколько раз ни отправь один и тот же запрос, состояние ресурса не изменится. POST — нет, каждый POST может создать новую сущность.

Чтобы сделать POST безопасным для повторов, используют заголовок Idempotency-Key. Клиент генерирует уникальный ключ, сервер запоминает результат и при повторе с тем же ключом возвращает сохранённый ответ, а не выполняет операцию заново.

Идемпотентность защищает от дублирования данных при повторных запросах — без неё в сети надёжный API не построить.
