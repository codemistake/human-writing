## Контекст

Сервисы общаются по REST. При трёх сервисах это работало. Сейчас их двадцать, и ограничения REST стали заметны.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины для контрактов между сервисами.

REST остаётся для внешнего API и браузера: grpc-web добавляет сложность, которая пока не оправдана.

## Последствия

Получаем строгие контракты, генерацию клиентов и меньший оверхед. Взамен — команде придётся освоить новый инструментарий.
