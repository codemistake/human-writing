## Контекст

Сервисы общаются по REST. Это работало при трёх сервисах. Сейчас их двадцать, и REST достиг своих ограничений.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины для контрактов между сервисами.

REST остаётся для внешнего API и браузера: grpc-web добавляет сложность, которая сейчас не оправдана.

## Последствия

Строгие контракты, генерация клиентов, меньший оверхед. Команде придётся освоить новый инструментарий — это ожидаемые затраты времени.
