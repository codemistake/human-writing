## Контекст

Наши сервисы общаются по REST. Это работало, пока сервисов было три. Сейчас их двадцать, и REST показывает свои ограничения.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины для контрактов между сервисами.

REST остаётся для внешнего API и для браузера: grpc-web добавляет сложность, которая на текущем этапе не оправдана.

## Последствия

Мы получаем строгие контракты, генерацию клиентов и меньший оверхед. Взамен команде придётся освоить новый инструментарий. Считаем, что это окупится.
