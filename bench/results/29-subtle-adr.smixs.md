## Контекст

Наши сервисы общаются по REST. Это работало, пока сервисов было три. Сейчас их двадцать, и REST начинает показывать свои ограничения.

## Решение

Мы переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины.

REST остаётся для внешнего API и для браузера, потому что grpc-web добавляет сложность, которая на текущем этапе не оправдана.

## Последствия

Мы получаем строгие контракты, генерацию клиентов и меньший оверхед. Команде придётся освоить новый инструментарий - мы считаем это оправданным компромиссом.
