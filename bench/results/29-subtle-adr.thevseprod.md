## Контекст

Наши сервисы общаются по REST. Это работало, пока сервисов было три. Сейчас их двадцать, и REST начинает показывать свои ограничения.

## Решение

Переходим на gRPC для межсервисного взаимодействия. Схемы protobuf становятся единственным источником истины для контрактов между сервисами.

REST остаётся для внешнего API и для браузера: grpc-web добавляет сложность, которая на текущем этапе не оправдана.

## Последствия

Получаем строгие контракты, генерацию клиентов и меньший оверхед. Команде придётся освоить новый инструментарий.
