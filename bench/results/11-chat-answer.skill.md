Разница между git rebase и git merge: merge создаёт новый коммит слияния и оставляет историю как есть, rebase переписывает историю, перенося твои коммиты поверх целевой ветки.

После rebase понадобится force push — это может сломать работу коллег, если ветка общая. Поэтому для общих веток лучше merge, а rebase — для локальных.
