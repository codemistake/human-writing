## 4.1

Новое:
- параметр `retry` - число повторов запроса, по умолчанию 0
- `timeout` разделён на `connect_timeout` и `read_timeout`; старый `timeout` продолжает работать, но помечен deprecated

Требования:
- минимальная версия Python - 3.10 (была 3.9)

Исправления:
- #412: утечка соединений при исключении внутри контекстного менеджера
- #398: неверная кодировка заголовков с не-ASCII символами
