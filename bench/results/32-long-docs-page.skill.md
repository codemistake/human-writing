# Вебхуки

## Что такое вебхук

Вебхук — это HTTP-запрос, который наша система отправляет на указанный вами URL при наступлении события. Инициатор запроса — система, а не вы: не нужно опрашивать API, чтобы узнать об изменениях, — это снижает нагрузку и задержку по сравнению с поллингом.

## Настройка

1. Перейдите в раздел `/settings/webhooks` в личном кабинете.
2. Нажмите «Добавить вебхук» и укажите URL обработчика.
3. Выберите события, о которых хотите получать уведомления, например `payment.succeeded`.
4. Сохраните секретный ключ — он показывается только один раз.

## Проверка подписи

Каждый запрос подписывается HMAC-SHA-256, подпись передаётся в заголовке `X-Signature`. Проверяйте подпись для каждого входящего запроса, чтобы отсечь подделки.

Чтобы проверить подпись: вычислите HMAC-SHA-256 от тела запроса с использованием секретного ключа и сравните результат со значением заголовка.

## Повторные попытки

Обработчик должен ответить кодом `2xx` в течение 5 секунд. Если ответа нет или код отличается от `2xx`, система повторит отправку — всего 3 попытки с возрастающим интервалом. После неуспешных попыток событие помечается как недоставленное; отправить его повторно вручную можно из личного кабинета в течение 24 часов.

## Рекомендации

Обработчик должен быть идемпотентным: одно и то же событие может прийти больше одного раза. Отвечайте на запрос сразу, а обработку выполняйте асинхронно.
