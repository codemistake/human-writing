# Вебхуки

## Введение

Вебхуки — способ получать уведомления о событиях в реальном времени. По сравнению с опросом API они снижают нагрузку и задержку, поэтому это предпочтительный способ интеграции.

## Что такое вебхук

Вебхук — это HTTP-запрос, который наша система отправляет на указанный вами URL при наступлении события. Инициатор запроса — наша система, а не ваша.

## Настройка

Чтобы начать получать вебхуки:

1. Перейдите в раздел `/settings/webhooks` в личном кабинете.
2. Нажмите «Добавить вебхук» и укажите URL вашего обработчика.
3. Выберите события, о которых хотите получать уведомления, например `payment.succeeded`.
4. Сохраните секретный ключ, который система сгенерирует после настройки, — он будет показан только один раз.

## Проверка подписи

Каждый запрос подписывается HMAC-SHA-256, подпись передаётся в заголовке `X-Signature`. Проверяйте подпись для каждого входящего запроса — это защита от подделки.

Чтобы проверить подпись, вычислите HMAC-SHA-256 от тела запроса с секретным ключом и сравните результат со значением заголовка.

## Повторные попытки

Обработчик должен ответить кодом `2xx` в течение 5 секунд. Если ответа нет или код не `2xx`, система повторит отправку — всего 3 попытки с увеличивающимся интервалом. Если все попытки не удались, событие помечается недоставленным: его можно отправить повторно вручную из личного кабинета в течение 24 часов.

## Рекомендации

Обработчик должен быть идемпотентным: одно и то же событие может прийти больше одного раза. Отвечайте на запрос сразу, а обработку выполняйте асинхронно.

## Заключение

Вебхуки позволяют строить надёжную интеграцию в реальном времени без опроса API.
