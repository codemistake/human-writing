Разница между git rebase и git merge вот в чём. Merge создаёт новый коммит слияния и не трогает историю. Rebase переписывает историю: переносит твои коммиты поверх целевой ветки. После rebase понадобится force push — а это может подгадить коллегам, которые работают в той же ветке. Поэтому для общих веток лучше merge, а rebase — только для локальных.
