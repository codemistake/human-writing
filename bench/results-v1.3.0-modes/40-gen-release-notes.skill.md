# 4.1

- Добавлен параметр `retry` — число повторов запроса, по умолчанию `0`.
- Параметр `timeout` разделён на `connect_timeout` и `read_timeout`. Старый `timeout` продолжает работать, но помечен как deprecated.
- Минимальная версия Python поднята с 3.9 до 3.10.
- Исправлен баг #412: утечка соединений при исключении внутри контекстного менеджера.
- Исправлен баг #398: неверная кодировка заголовков с не-ASCII символами.
